# Ratings explorer for films and albums

Open **Ratings** beside **Browse** in Films or Albums. Adjust the source weights to rank the library, then select a title, score or rating to inspect its calculation and open the stored evidence. The browser remembers scoring settings separately for the two libraries. Sources, Agreement and Compare are planned in subsequent releases.

## Ranking and scoring

- Rank the visible library members of the selected media type using the same membership, hidden-item and album edition rules as Browse. Use the existing field registry for built-in and plugin ratings, including their native scale and optional vote-count field. Include the personal film rating with an initial weight of zero. Use an unclassified group for sources without a declared audience or critic role.
- Search titles and directors or artists. Filter by tag, year, watched status for films, play count for albums and whether an item has a combined score. Sort either way by a source, combined score, spread, ratings counted, year, title, critic–audience gap or personal–combined gap where available. Missing sort values come last in either direction. Preserve ties with a stable item ID. Allow native or adjusted values in the rating columns.
- Start with each source's percentile within its library, averaging tied ranks. Offer scale-only conversion to 0–100 and standardisation to a mean of 50 with 20 points per population standard deviation, clipped to 0–100. An entirely tied source has an adjusted percentile and standardised value of 50. The reference population stays fixed when searching, filtering or paging.
- Start with a weighted mean, weights of one for public sources, a two-rating minimum and no vote floor. Accept weights from 0 to 3 in half steps and an optional vote floor for sources that report votes. Offer a weighted median (average the two middle values at an exact split) and a trimmed mean (drop one high and one low when at least four ratings qualify). Show how many ratings qualified and which contributed to the mean.
- Keep a genuine zero rating when the source permits it. For a source with a vote field, zero with no supporting votes is an unrated placeholder. Sources such as IMDb also require votes behind a positive rating. Remove placeholders, malformed values and out-of-scale values before computing the source's distribution. Show unknown votes separately from zero votes. With a positive vote floor, both fall below the threshold. A source with no observations in this library contributes no baseline.
- Optionally omit an outlier only if at least three eligible ratings exist and a strict majority lies within the selected distance of their unweighted median. Start this rule switched off, with a distance of 25 points. Missing or excluded positive-weight sources may count as zero, half (default) or full weight at their source average. Weight-zero sources have no influence. The minimum counts observed qualifying ratings after outlier removal, before trimmed-mean extrema are dropped. Show an unscored item and its shortfall on request.
- Each result opens its calculation in the shared inspector. Show raw score and scale, votes, adjusted value, weight, eligibility and any exclusion, the combination step, the observed and missing weights, and the displayed result using the same rounding as the table. In a trimmed mean the extrema leave the mean's numerator and denominator, and the inspector separately shows the qualifying weight used for the missing-rating adjustment. Link to the item's stored Sources evidence, preserving separate score and vote provenance when available.

## Planned views: Sources, Agreement and Compare

- **Sources** shows coverage and histograms of native ratings, combined score, spread and counted sources. Select a bin or range to filter the other views. Each histogram counts items matching every other filter. Give the numerator and denominator for coverage and distinguish recorded ratings from ratings used in a score.
- **Agreement** shows the correlation and shared-item count for each source pair, the sources that score systematically higher or lower than their peers, and the items with the largest disagreements. Spread is the unweighted population standard deviation of at least two qualifying adjusted ratings. With three or more, identify the source furthest from the mean of the others when there is a difference. Report pairwise Pearson correlation for at least 20 shared items with variation on both axes. Show the reason when it is unavailable.
- **Compare** opens from a pair or from the view switch. Plot source ratings, combined scores, critic or audience averages, spread or year, with selectable axes. Show overlap, signed differences on comparable axes and a route from a point or group of points to the contributing items. Agreement and Compare use the same vote-qualified pairs under the same filters. Weights and outlier rules affect the composite, while comparisons between the original sources retain the evidence of disagreement. A library with zero or one source still opens.

## Read API and checks

The browser needs one page of ranked items or a chart summary. Global percentiles and arbitrary weighted sorts need the visible cohort. Compute them server-side from stored fields, then apply display filters and order before paging. This keeps the response bounded as the library grows.

| Interaction                             | Feature request and result                                                                                                                                                                                                                                        |
| --------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Open Ratings or commit a scoring change | One authenticated ranking request for one library. Return the page of item IDs, display fields and compact rating values with its source definitions. Reuse the shared table paging pattern. Measure any exact count separately from time to first rows.          |
| Drag a weight or type a search          | Update the control locally. Commit once per drag or keyboard adjustment sequence, debounce search, cancel superseded reads and discard late responses.                                                                                                            |
| Open a calculation                      | One read at most for the selected visible item with the same scoring settings. Other rows and unopened views issue no requests.                                                                                                                                   |
| Open a chart                            | Fetch the active view's aggregate in one request. Bound histogram bins, source pairs per page, and plotted points or density cells. Compute counts and correlation on the complete matching cohort. Label sampled or grouped points and allow bounded drill-down. |

Use the existing owner access middleware and private response caching policy. Validate request and response shapes with shared schemas. Bind registered rating keys literally, including dotted plugin keys. Bound page size, filter and settings lists, text length, axes and numeric parameters. Use stored values throughout the explorer. Opening a view or changing a weight must issue zero provider calls, enqueue zero jobs and transfer zero raw provider payloads. Key the in-memory query cache by library and effective settings, and invalidate affected reads on library changes.

Deliver Ranking, Scoring and item evidence for both libraries first, then Sources, then Agreement and Compare. Build with the shared toolbar, segmented control, secondary table, condition, histogram, stats and inspector. Verify each release at desktop and phone widths on disposable data. For API changes, follow the [query performance checks](../query-performance.md#performance-review-for-a-feature).

### Acceptance examples

- A source reporting 2, 4, 4 and 8 yields percentiles 12.5, 50, 50 and 87.5. Searching down to one of the tied items leaves its 50 unchanged.
- With scale-only values 80 and 20 weighted 2 and 1, the mean is 60 and the spread is 30. A third, missing source with weight 1 and average 50 changes the default combined score to 58.57. Absolute numbers in the inspector must reproduce the displayed score.
- At a 25-point outlier distance, 10, 80 and 82 exclude 10. The split 10, 12, 80 and 82 retains both groups. A missing value, a valid zero, an all-missing source and an all-zero weight configuration have distinct results.
- Verify authentication, invalid settings and source keys, personal and plugin fields, visibility in both libraries, deep and empty pages, exact ties, a rating edit followed by a read, and the matrix-to-Compare overlap. Measure response bytes, feature requests, SQL statements, logical reads and temporary blocks on representative synthetic data. Page response size must stay bounded as the fixture grows.

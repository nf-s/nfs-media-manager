# Service Marks

`spotify.svg` is the black RGB icon (`Primary_Logo_Black_RGB.svg`) from Spotify's [official icon archive](https://developer.spotify.com/images/guidelines/design/2024-spotify-logo-icon.zip), downloaded 2026-10-27 through its [Design & Branding Guidelines](https://developer.spotify.com/documentation/design). The original path, viewBox and color are unchanged. Spotify's trademark remains its owner's; this is not a CC0 asset.

Service links also reuse the existing legacy assets `/img/lastfm.png` (Last.fm, 64 x 64) and `/img/mb.png` (MusicBrainz, 220 x 220), as referenced by `legacy/web-src/Models/Album.tsx`. Their original download URLs and licenses are not recorded in the legacy source; trademarks remain their owners'.

Other recognized services reuse the existing marks documented in [Rating Marks](../ratings/README.md). All icons are served locally, with no runtime requests to brand hosts.

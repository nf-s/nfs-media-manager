# One-colour logos

Service and provider logos are drawn in one muted ink by the shared `ProviderMark`, which uses each file only as a shape (a CSS mask). Most logos come straight from the files in [ratings](../ratings/README.md), [services](../services/README.md) and `/img`. The files here are one-colour versions of logos whose colour file loses its inner mark as a plain shape, and one-colour marks for services with no colour file here:

- `lastfm.png`: derived from `/img/lastfm.png`, with the white letters cut out of the disc.
- `rym.png`: derived from `../ratings/sonemic.png`, keeping the dark waves and dropping the light sky and rim.
- `youtube.svg`: the local geometric YouTube mark from `../ratings/youtube.svg`, with the play triangle cut out.
- `letterboxd.svg`: the local three-circle Letterboxd mark from `../ratings/letterboxd.svg`, with the overlaps cut out.
- `tidal.svg`: a local geometric rendering of TIDAL's four-diamond mark, three diamonds over one.

They are served locally, with no requests to brand hosts. Trademarks remain their owners'.
